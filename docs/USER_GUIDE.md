# Benutzerhandbuch

## Installation

1. Lade den Installer für dein Betriebssystem herunter
2. Führe die Installation aus
3. Starte die App

## Erste Schritte

### Master-Passwort

Beim ersten Start musst du ein Master-Passwort festlegen. Dieses Passwort wird für die Verschlüsselung aller Daten verwendet.

**Wichtig**: Es gibt keinen Passwort-Reset. Bei Verlust des Passworts sind alle Daten unwiderruflich verloren.

### Dokumente scannen

1. Klicke auf "Scannen" in der Seitenleiste
2. Ziehe Dateien in das Upload-Feld oder klicke "Dateien auswählen"
3. Die OCR-Erkennung startet automatisch
4. Überprüfe die erkannten Daten im Validierungs-Dialog
5. Bestätige oder überspringe die Validierung

### Dokumente verwalten

- **Ansicht**: Wechsle zwischen Grid- und Listenansicht
- **Filter**: Nutze die Filter-Optionen in der Suche
- **Tags**: Füge Tags zu Dokumenten hinzu für bessere Organisation
- **Verknüpfungen**: Verknüpfe verwandte Dokumente miteinander

### Suche

Die Volltextsuche durchsucht alle OCR-Texte, Dateinamen und Tags.

## Einstellungen

- **Allgemein**: Sprache, Autostart
- **OCR**: Konfidenz-Schwellenwert, Sprache
- **Speicher**: Pfad, Backup-Einstellungen
- **Kategorien**: Verwaltung der Kategorien
- **Entwickler**: Debug-Tools (passwortgeschützt)

## Tastenkombinationen

- `Strg+N`: Neues Dokument scannen
- `Strg+F`: Suche öffnen
- `Strg+,`: Einstellungen öffnen
- `Strg+L`: App sperren
